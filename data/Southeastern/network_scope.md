# Southeastern Network Scope

## Purpose

Defines the station coverage for the Southeastern network within *The Route*.

The Southeastern network represents one of the most varied commuter rail systems in Britain, combining intensive suburban services, major Kent main lines, High Speed services, coastal routes, and rural branch lines.

The network provides a strong mix of commuter, regional and coastal stations, creating a diverse puzzle environment with numerous route identities and interchange opportunities.

## Exclusions

The following are excluded from this network:

* Southern-operated routes outside agreed shared stations
* Thameslink-only stations
* London Underground services
* London Overground services
* Freight-only infrastructure
* Heritage railways

Stations shared with Southern may appear in both games where appropriate.
